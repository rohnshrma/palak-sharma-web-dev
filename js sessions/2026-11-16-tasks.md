# Practice Tasks: 16 Nov 2026

**Covered today:** objects (creating, reading with dot and bracket notation, updating a value, adding a new property), constructor functions (`this`, `new`, methods), classes (fixed class fields, filling values through a method, `constructor`, methods that `return`), XMLHttpRequest (`readystatechange`, `readyState`, `status`, `responseText`, `open`, `send`).

Write each task in a fresh `.js` file and check every `console.log` against what you *expected* before you ran it. Use only what's listed above, plus arrays, loops, functions and if/else from earlier classes. Part E needs the browser, so link that file to an HTML page and check the console there.

## Part A: Objects (basic)

**A1. Your first object**
Make an object called `phone` with 4 properties: `brand`, `model`, `price` and `colors` (an array of 3 colours). Print the whole object.

**A2. Two ways to read**
Using `phone` from A1, print the `brand` once with dot notation and once with bracket notation. Write a comment saying whether both gave the same value.

**A3. Reading from the array inside**
Using `phone` from A1, print only the first colour and only the last colour from the `colors` property.

**A4. Update a value**
Make an object `student` with `name`, `age` and `city`. Print it. The student has a birthday: change `age` to one more than before. Print the object again.

**A5. Add a new property**
Using `student` from A4, add a new property `isEnrolled` with the value `true`. Print the object. Write a comment saying how many properties it has now.

**A6. Update or add?**
Make an object `laptop` with `brand` and `ram`. Write these two lines and, before running, write in a comment which one updates and which one adds, and why:
`laptop.ram = 16;`
`laptop.storage = 512;`
Print the object and check.

**A7. Key that is not there**
Make an object `book` with `title` and `author`. Print `book.price`. Write a comment explaining what you got and why.

**A8. Sentence from an object**
Make an object `movie` with `name`, `year` and `rating`. Using a template literal, print one sentence like: `Sholay released in 1975 and has a rating of 8.1`.

**A9. Bill from an object**
Make an object `item` with `name`, `price` and `quantity`. Add a new property `total` whose value is `price` multiplied by `quantity` (calculate it from the object's own values, do not type the answer). Print the object.

## Part B: Constructor functions

**B1. Your first constructor**
Write a constructor function `GenBook` that takes `title`, `author` and `pages`. Create 2 different books with it and print both.

**B2. Add a method**
Add an `info` method to `GenBook` that prints: `<title> is written by <author>`. Call it on both books.

**B3. Employee**
Write a constructor function `GenEmployee` with `name`, `department` and `salary`. Give it a method `showSalary` that prints: `<name> earns <salary> per month`. Create 3 employees and call the method on each.

**B4. Change after creating**
Using one employee from B3, change the `salary` to a higher number and add a new property `isManager` set to `true`. Print the employee and call `showSalary` again.

**B5. Explain `new`**
Above your `GenEmployee` function, write a comment listing the 3 things the `new` keyword does, in your own words.

**B6. Array of objects**
Using `GenBook`, create 3 books and put them in an array. Use a loop to call `info` on each book.

## Part C: Classes (fixed values and values through a method)

**C1. Fixed values**
Make a class `Laptop` with three fixed fields: `brand`, `ram` and `price`. Add an `info` method that prints all three in one sentence. Create 2 objects and call `info` on both.

**C2. Same or different?**
Print both objects from C1. Write a comment saying whether their data is the same or different, and what the drawback of this type of class is.

**C3. Values through a method**
Make a class `Mobile` with no fields. Give it a method `takeValues(brand, model, price)` that stores the values using `this`, and an `info` method that prints them in one sentence. Create an object, call `takeValues`, then call `info`.

**C4. Two different mobiles**
Using `Mobile` from C3, create 2 objects with different values. Print both objects and call `info` on both.

**C5. Forgot to fill**
Using `Mobile` from C3, create a third object but do **not** call `takeValues`. Print the object and call `info`. Before running, write in a comment what you think will be printed and why.

**C6. Print before and after**
Create a `Mobile` object. Print it. Call `takeValues`. Print it again. Write a comment explaining the difference between the two prints.

## Part D: Classes with constructor

**D1. Your first constructor class**
Make a class `Student` with a `constructor(name, age, course)`. Create 3 students in a single step each and print all three.

**D2. Method that returns**
Add an `info` method to `Student` that **returns** (not prints) the string: `<name> is <age> years old and studies <course>`. Store the result in a variable and then print the variable.

**D3. return vs console.log**
Make a class `City` with a `constructor(name, state)`. Give it two methods: `show()` which prints `<name> is in <state>`, and `details()` which returns the same string. Store the result of both in variables and print the variables. Write a comment explaining what each variable holds.

**D4. Rectangle**
Make a class `Rectangle` with `constructor(length, width)`. Add a method `area()` that returns the area and a method `perimeter()` that returns the perimeter. Create 2 rectangles and print the area and perimeter of each.

**D5. Bank account**
Make a class `Account` with `constructor(holder, balance)`. Add a method `deposit(amount)` that adds the amount to `balance`, and a method `showBalance()` that returns: `<holder> has Rs. <balance>`. Create an account, deposit twice, and print `showBalance()` after each deposit.

**D6. Same thing, three ways**
Take the idea of a `Bike` with `model`, `brand` and `mileage`. Write it three times as three separate classes: once with fixed values, once with a `takeValues` method, and once with a `constructor`. Create one object from each and print them. In a comment, write which way you would use and why.

**D7. Constructor function to class**
Take `GenEmployee` from B3 and write the same thing as a class called `Employee` with a `constructor`. Create the same 3 employees and call `showSalary` on each. The output must match B3.

**D8. Array of class objects**
Using `Student` from D1, put 4 students in an array. Use a loop to print the result of `info()` for each one.

## Part E: XMLHttpRequest

**E1. Your first request**
Write a request to `https://v2.jokeapi.dev/joke/Programming?type=single`. When the request is complete and successful, print `responseText`.

**E2. Watch the stages**
In the same code, print `request.readyState` every time the `readystatechange` event fires. Write a comment listing the numbers you saw and what each one means.

**E3. Watch the status**
Print `request.status` along with `request.readyState` each time the event fires. Write a comment saying at which stage the status became `200`.

**E4. Why check both?**
Remove the `request.status === 200` part from your `if` and keep only `readyState === 4`. Then change the URL to a wrong one (for example add `xyz` at the end of the path). Write a comment explaining what got printed and why checking only `readyState` is not enough.

**E5. Handle failure**
Using the wrong URL from E4, add a second `if` that prints `Something went wrong` along with the status code when the request is complete but not successful.

**E6. Change the category**
Change the URL so that the joke comes from the `Spooky` category only. Then change it to get jokes from both `Programming` and `Spooky`. Run each and check the output.

**E7. Order of lines**
Add `console.log("request sent")` just after `request.send()`. Run it and see whether this line prints before or after the joke. Write a comment explaining why.

**E8. Before open**
Print `request.readyState` just after creating the request, again just after `open()`, and again just after `send()`. Write a comment with the three values you saw.

**E9. Label the output**
When the request is successful, print the response with a label in front, like: `JOKE DATA : <responseText>`. When it fails, print: `FAILED WITH STATUS : <status>`.

**E10. Two requests**
Create two separate request objects, `request1` and `request2`, each going to the joke URL, each with its own listener. Print the response of each with a label (`first :` and `second :`). Run it a few times and write a comment on whether the order is always the same.
