# Practice Tasks: 14 Oct 2026

**Covered today:** arrays (creating, `length`, indexes, `.at()`, `+` vs `.concat()`, `push`, `pop`, `unshift`, `shift`, `splice`), function expressions (anonymous and arrow functions), higher order functions and callbacks.

Write each task in a fresh `.js` file (or at the bottom of `array.js` / `functions.js`), run it in the browser console, and check every `console.log` against what you *expected* before you ran it. Don't use any array method we haven't covered yet (no `map`, `filter`, `indexOf`, `includes`, etc.). Use only what's listed above, plus loops and if/else from earlier classes.

## Part A: Arrays (basic)

**A1. Your first array**
Make an array called `fruits` with 5 fruit names in it. Print the whole array, then print how many fruits it has using `length`.

**A2. First and last**
Using the `fruits` array from A1, print the first fruit using square brackets. Then print the last fruit in two different ways: once with `length - 1` and once with `.at()`. Write a comment explaining why both ways give the same item.

**A3. Mixed array**
Make one array that holds a number, a string, a boolean, and another number. Print each item on its own line using its index. Write a comment saying what type each item is.

**A4. Out of range**
Make an array of 4 numbers. Try to read the item at index 10 using square brackets, and again using `.at(10)`. Print both. Write a comment explaining what you got and why.

**A5. Counting from the end**
Make an array of 6 city names. Using only `.at()` with negative numbers, print the last city, the second last city, and the third last city.

**A6. The `+` trap**
Make two small arrays of numbers. Print them added together with `+`. Then use `typeof` on that result and print it. Then join the same two arrays properly with `.concat()` and print that. In a comment, explain in your own words why `+` didn't do what you wanted.

**A7. Does concat change the original?**
Make two arrays `x` and `y`. Store `x.concat(y)` in a new variable called `joined`. Print `x`, `y`, and `joined`. Write a comment saying whether `x` changed or not.

## Part B: Arrays (adding and removing)

**B1. Shopping list**
Start with an empty array `cart = []`. Use `push` to add 3 items one at a time, printing the array after each push. Then add 2 more items in a single `push` call and print again.

**B2. Queue at a counter**
Make an array of 4 customer names standing in a line. The person at the front gets served: remove them with the right method and print who's left. Then a new person joins at the back: add them and print the line again.

**B3. Undo button**
Make an array `history` with 5 page names a user visited, in order. The user presses "back" twice: remove the last two pages one at a time, printing the array after each removal.

**B4. VIP entry**
Make an array of 3 guest names. Two VIPs arrive and must go to the very front of the list, in the order you write them. Add them in a single call and print the list.

**B5. Store what you remove**
`pop` and `shift` give back the item they removed. Make an array of 5 numbers. Store the result of `pop()` in a variable and the result of `shift()` in another variable. Print both variables and then the array.

**B6. Watch the length change**
Make an array of 3 numbers and print its `length`. Do one `push`, one `unshift`, one `pop` and one `shift`, and print `length` after every single step. Before running, write in a comment what you think the length will be at each step.

## Part C: splice (intermediate)

**C1. Add in the middle**
Make `nums = [10, 20, 40, 50]`. Use `splice` to put `30` in its correct place so the numbers are in order, without removing anything. Print the array.

**C2. Fix a typo**
Make an array `days` with 5 weekday names but spell the third one wrong. Use `splice` to replace only that wrong item with the correct spelling. Print the array.

**C3. Remove from the middle**
Make an array of 6 colours. Use `splice` to remove the 2nd and 3rd colours in one call. Print the array.

**C4. Remove and replace more than one**
Make an array of 6 numbers. In a single `splice` call, remove 2 items starting from index 2 and put 3 new numbers in their place. Print the array and its new `length`.

**C5. Playlist manager**
Make an array `playlist` with 4 song names. Do all of these in order, printing the playlist after each step:
1. Add a song to the end.
2. Add a song to the beginning.
3. Insert a song at index 2 without removing anything.
4. Replace the song at index 3 with a different one.
5. Remove the last song.
6. Remove the first song.

Pick the right method for each step yourself.

## Part D: Function expressions

**D1. Anonymous function in a variable**
Write an anonymous function stored in a variable called `multiply` that takes two numbers and returns their product. Call it 3 times with different numbers, store each result in a variable, and print it.

**D2. Same thing, arrow style**
Rewrite `multiply` from D1 as an arrow function called `multiplyArrow`. First write it with `{}` and `return`, then write a second version in one line without `{}` or `return`. Call both and print the results.

**D3. Arrow with one parameter**
Write an arrow function `cube` that takes one number and gives back that number to the power of 3 (use `**`). Call it with 3 different numbers and print each result.

**D4. Arrow with no parameters**
Write an arrow function `sayHi` with no parameters that returns the string `"Hi there!"`. Call it and print the result. Notice what the empty `()` is doing.

**D5. Current year**
Write an arrow function `currentYear` that returns `new Date().getFullYear()`. Then write another arrow function `ageFromYear` that takes a year of birth and returns the age, using `currentYear()` inside it. Test it with your own birth year and two others.

**D6. Arrow with if/else inside**
Write an arrow function `checkPass` that takes marks and returns `"pass"` if marks are 33 or more, otherwise `"fail"`. Since it needs if/else, use `{}` and `return`. Test with 3 values.

**D7. Function that takes an array**
Write an arrow function `firstAndLast` that takes an array and prints its first item and its last item (use `.at()` for the last). Call it with two different arrays.

**D8. Function that changes an array**
Write an arrow function `addToCart` that takes an array and an item, pushes the item into the array, and returns the new length. Call it twice on the same array and print the array at the end.

## Part E: Callbacks and higher order functions (intermediate)

**E1. Spot the parts**
Look at the `lifeSpan` example from class. In a comment, write which one is the HOF, which one is the callback, and which parameter is holding the callback inside the HOF.

**E2. Calculator with a callback**
Write a HOF arrow function `calculate` that takes `a`, `b`, and a callback `operation`. Inside, it should call `operation(a, b)` and print the result. Then:
1. Make separate arrow functions for add, subtract, multiply and divide, each stored in its own variable.
2. Call `calculate` 4 times, passing each of them in by name (no `()` after the name).

**E3. Callback written on the spot**
Call the same `calculate` from E2 two more times, but this time write the callback directly inside the call (like we did with `lifeSpan`), once for finding the remainder (`%`) and once for power (`**`).

**E4. Greeting maker**
Write a HOF `greet` that takes a name and a callback `style`. It should print whatever `style(name)` returns. Write two callbacks: one that returns a formal greeting and one that returns a casual greeting (use template strings). Call `greet` with each.

**E5. Discount calculator**
Write a HOF `finalPrice` that takes a price and a callback `discountRule`. The callback takes the price and returns the discount amount. `finalPrice` should print the price after taking the discount off. Test it with:
- a callback that gives a flat ₹100 off,
- a callback that gives 10% off,
- a callback that gives 20% off only if the price is more than 1000, otherwise nothing.

**E6. Run a callback on every item**
Write a HOF `forEachItem` that takes an array and a callback. Inside, use a `for` loop to go through the array and call the callback with each item. Test it by passing:
- a callback that prints each item,
- a callback that prints each item doubled,
- a callback that prints the item only if it's even.

**E7. Retirement countdown**
Following the `lifeSpan` pattern, write a HOF `yearsToRetire` that takes the retirement age, a year of birth, and an age callback. It should work out the current age using the callback and print how many years are left until retirement. If the person has already passed retirement age, print a different message instead. Pass the age callback in two ways: once as a stored arrow function by name, and once written directly inside the call.

**E8. Callback that builds an array**
Write a HOF `collect` that takes a number `n` and a callback. It starts with an empty array, loops from 1 to `n`, calls the callback with each number, and pushes whatever the callback returns into the array. At the end it returns the array. Test it with a callback that squares the number and another that returns the number times 10. Print both arrays.
